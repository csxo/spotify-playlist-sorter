## English

This is the standalone Chrome Extension version (Manifest V3) of **Spotify Playlist Auto Sorter**.

### Installation Steps:
1. Open Google Chrome, navigate to:
   ```text
   chrome://extensions/
   ```
2. Enable **Developer mode** in the top-right corner.
3. Click the **Load unpacked** button in the top-left corner.
4. Select the extension directory:
   ```text
   D:\AI Projects\Antigravity Projects\spotify-playlist-sorter\extension
   ```
5. Open [Spotify Web Player (open.spotify.com)](https://open.spotify.com/), navigate to any of your playlists.
6. Look for the `🎵 Sort Playlist` button directly in the action bar, or click the extension icon in the toolbar!

## 简体中文

这是本排序工具的 Chrome 扩展版本（Manifest V3）。

### 安装步骤：
1. 打开 Chrome 浏览器，在地址栏输入：
   ```text
   chrome://extensions/
   ```
2. 在页面右上角开启 **“开发者模式” (Developer mode)** 开关。
3. 点击页面左上角的 **“加载已解压的扩展程序” (Load unpacked)**。
4. 选择当前文件夹即可：
   ```text
   D:\AI Projects\Antigravity Projects\spotify-playlist-sorter\extension
   ```
5. 打开 [Spotify 网页版 (open.spotify.com)](https://open.spotify.com/)，进入您的任意歌单页面，操作栏将出现 `🎵 智能排序歌单` 按钮，点击即可直接使用！
