# Chrome 扩展安装说明 (Unpacked Extension)

这是本排序工具的 Chrome 扩展版本（Manifest V3）。

### 安装步骤：
1. 打开 Chrome 浏览器，在地址栏输入：
   ```text
   chrome://extensions/
   ```
2. 在页面右上角勾选开启 **“开发者模式” (Developer mode)**。
3. 点击页面左上角的 **“加载已解压的扩展程序” (Load unpacked)**。
4. 选择当前文件夹即可：
   ```text
   D:\AI Projects\Antigravity Projects\spotify-playlist-sorter\extension
   ```
5. 打开 [Spotify 网页版 (open.spotify.com)](https://open.spotify.com/)，进入您的歌单页面，右下角将出现绿色悬浮按钮 `🎵 智能排序歌单`，点击即可使用！
